## Featured project

### Digital platform for immigrant integration, recruitment and public services

Final degree project developed in collaboration with AMT Consulting. The platform centralises official guidance, job opportunities, document management and administrative support for immigrants, employers and public entities.

- Modular architecture on Next.js, NestJS, PostgreSQL and Prisma ORM, with external document storage and an AI-assisted candidate pre-screening API
- Role-based access control across four account types, each with its own permissions and visible surface
- Handling of identity documents and personal data
- User-centred design and usability evaluation with immigrant users, employers, public entities and administrators

Paper and poster: [10.5281/zenodo.24062401](https://doi.org/10.5281/zenodo.24062401)
